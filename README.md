#Campus Bridge

### Connecting Local and International Students

## About the Project

Campus Bridge is a web application designed to connect local and international students.

Our platform helps students communicate, find new friends, discover campus events, and feel more connected to university life.

## 🎯 Problem

International students may face difficulties adapting to a new university environment, finding friends, and communicating with local students.

Campus Bridge aims to make this process easier.

## 👥 Target Users

- Local university students
- International students
- Students looking for language partners
- Students interested in campus activities

## ✨ Main Features

- User Registration and Login
- Student Profiles
- Find a Buddy
- Student Directory
- Campus Events
